# 一路相随的图书馆 · 浙江大学西迁校史展

浙江大学课程传播实践作品。玩家以“学生策展人”的身份，查证西迁时期图书馆的四件展品，替它们写下有出处的展签，再亲手点亮。

- 在线参观：本仓库的 GitHub Pages 地址（仓库 Settings → Pages 中显示）。
- 建议使用最新版 Chrome、Safari 或 Edge；需要开启硬件加速（WebGL）。手机与电脑均可。
- 参考来源、素材许可与致谢见游戏内“参考来源与致谢”页（终场卡片或任务灯面板底部，或在网址后加 `?credits`）。

本作品仅作非商业的教学与展示用途。文中引文与历史图像的著作权归原作者与发布机构所有；
